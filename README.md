# 战争诗歌 · 鸦片战争篇（手机版）

一款波兰球（Polandball）画风的非对称 RTS。你扮演军费拮据的大清，指挥清军（黄球、冷兵器）对抗 AI 操控的排队枪毙英军（米字旗球）。

## 怎么玩

1. 解压后用手机浏览器打开 `index.html`（建议横屏）。
2. **布阵阶段**：
   - 点选左侧 A / B / C / D 四个框之一选中方阵；
   - 点「招募清军」花 2 两银子往当前框里放兵（钱只有 130~180 两，省着花）；
   - 点「开战！」进入战斗。右侧是未知敌情（有雾），不许偷看英军布阵。
3. **战斗阶段**：
   - 最前排 5 个是送的炮灰，自动冲锋、不可指挥，作用是替你挨枪、勾引英军打空 5 秒装弹 CD；
   - 点左上角「指挥」→ 点选一个方阵（头顶的 A/B/C/D 小标）→ 在战场上按住拖动画一条线，松手后该方阵沿线路前进；
   - 行军途中碰到英军会自动停下砍杀，走到线尽头后主动逼近敌军；
   - 每个方阵都可以这样下一道命令（想改就再点一次指挥）。

## 战术要点

- **炮灰骗 CD**：先让炮灰顶上，等英军两轮排射打完、在装弹真空期，主力再冲。
- **侧翼包抄**：别正面冲！画线绕到英军侧面/后面。英军转身要 1.5 秒，这就是你的破绽；贴脸之后冷兵器 1 秒一刀，怒气拉满（12 伤害）一刀一个。
- **别无脑全军平推**：正面排队枪毙会把你打成《南京条约》。

## 数值

- 清军：2 两/人，HP10，1 秒一刀，伤害随怒气在 4.5~12 之间浮动；不溃逃。
- 英军：HP10，5 秒一枪，打中固定 10 点必死；伤亡过大（>38%）会士气崩溃溃逃。
- 击杀一个英军缴获 5 两。
- 起始军费 ≤110 两并全歼英军，解锁「老佛爷的麻辣烫」彩蛋成就。

## 文件结构

```
（所有文件都在同一目录，直接打开 index.html）
index.html      入口
style.css       样式
config.js       所有数值（想调平衡改这里）
utils.js
units.js        清军 / 英军单位
ai.js           英军士气、预备队、分离
game.js         状态机、经济、指挥
render.js       渲染（含贴图）
input.js        触屏 + UI
main.js         主循环
bg.webp         战场背景
qing.webp       清朝球贴图
british.webp    英国球贴图
```

纯 HTML5 + Canvas，无依赖、无网络请求，离线可玩。
